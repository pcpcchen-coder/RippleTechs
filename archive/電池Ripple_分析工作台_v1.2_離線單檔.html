    CHARGER / BATTERY CO-DESIGN

    單級充電器省成本，合理嗎？

    有條件合理。把電池可接受的 ripple 納入充電器設計，可能降低級數、電容、磁性元件與散熱成本。但應先訂電池端的頻譜、RMS、峰值與溫升界限，再比較整機成本。

    先分清楚：級數不等於 ripple 大小

    單相、近似單位功率因數時，瞬時輸入功率含兩倍線頻脈動：50 Hz電網為100 Hz，60 Hz電網為120 Hz。若能量緩衝很少且電池電壓近似固定，電池電流可能接近0–2Idc。單級也能設計解耦；二級也能刻意容許ripple以縮小DC-link電容。理想平衡三相的總瞬時功率沒有相同的固有2f脈動。

    p(t) = Pavg[1 − cos(2ωline t)]
    i(t) ≈ Idc[1 − cos(2ωline t)]　[無顯著能量緩衝的理想單相例]
    m = Ipk / Idc；Ipp / Idc = 2m
    Pac/Pdc = ½m² × Re{Z}/Rdc　[正弦]

    以目前參數比較不同 ripple 幅度

    建議保留三個方案比較

    方案可能節省需納入的代價
    二級＋低ripple作基準完整轉換級與能量緩衝成本
    單級＋受控ripple轉換級／DC-link與被動元件較高峰值／RMS、控制與EMI、散熱、電池驗證
    部分解耦／縮小電容折衷削減體積與BOM小型解耦元件、控制複雜度

    成本判斷應用「BOM與製造節省 − 新增解耦／散熱／EMI／驗證成本 − 能耗差額 − 電池壽命與保固成本」。級數變少不保證整機效率或成本較佳；也不要把0.23%的速率數值直接換成電池折舊。

    驗收分兩層

    1. 短期電氣與熱：相同平均充電任務、環境與冷卻條件，比較電芯／接點溫升、峰值電流、單體峰值電壓、CC–CV時間、充入Ah／Wh、BMS判斷，以及輸入功率品質／EMI。界限依電芯與系統規格制定。
    2. 中長期壽命：同批DC與ripple對照，匹配SOC／DoD／Ah；一組同冷卻邊界比較總影響，另一組同電池溫度以分離直接ripple效應。以容量、阻抗與統計不確定度作判準。

    與此用途直接相關的研究

    Ghassemi et al., 2019：13顆LFP的100 Hz實驗在其條件下未觀察顯著額外衰退，支持縮小電容的研究方向。2022延伸研究指出幅度、頻率與極化需要合併判斷，低頻微循環可能增加衰退。以上已核對作者機構摘要，不能直接當作本電芯的允許值。

    Xue et al., 2015在二級架構實作容許兩倍線頻的正弦充電以縮小DC-link電容，說明可節省緩衝能量的方案不只「二級改一級」。

    原頁問題修正後的表述
    1｜總結／電壓文字 75 A，波形均值約 ±39.03 A；5.38 A 未在總結註明 pp。熱與老化箭頭方向錯誤。5.38 App = 2.69 Apk = 1.9021 Arms（正弦）。39.03 A、75 A 分開計算。40 mVpp 只反推出 |Z| ≈ 7.4349 mΩ；不可直接假設為 DCIR。
    2｜SOC 範圍峰值標 79 A，與 75 + 2.69 = 77.69 A 不符。缺原始 OCV 表、電阻與精確端點。0.016% 的定義含糊。0.016 數值保留為「未驗證」，不能由截图精確復算。以 OCV 反函數重算上下界，分別列 SOC 百分點損失與相對縮減率。1.15 V 是設定門檻差，不是可用容量。
    3｜熱影響0.24% 只適用 39.03 A 且 AC/DC 同電阻。稱與內阻無關過度簡化。Pac/Pdc = (Iac,rms/Idc)² × Re{Z}/Rdc。原圖條件為 +0.237508%；75 A 同 ripple 時為 +0.064321%。這是額外發熱功率比例。
    4｜老化Arrhenius 指數少負號；比值與增量混淆；以速率增量直接稱 SOH degradation。k = A exp(−Ea/RT)。AF = exp[(Ea/R)(1/Tdc − 1/Tac)]。原圖條件 AF ≈ 1.002260；速率增加 +0.225993%，不是 SOH 減少 0.23 個百分點。
    5｜文獻作者與年份誤植；將指定條件的結果擴張為無直接老化、>10 Hz 無影響、額外老化 <0.15%。移除通用 10 Hz 與 0.15% 上限；改為電芯、波形、幅度、SOC 與溫控條件相關，需匹配實測。

    Bala et al., 2012：研究針對 LFP 系統的低頻 ripple 與熱／平衡／往返效率；本文未取得可核讀的完整一手實驗資料，故不將其當成通用壽命或 <0.15% 的證據。論文 DOI

    Korth Pereira Ferraz & Kowal, 2019：在其 NMC 18650 與約 5 kHz 轉換器測試條件下，ripple 效應未明顯超過循環深度造成的衰退；不宜推廣為所有 LFP 的保證。原論文

    電池端開關漣波

    占空比、發熱與濾波拓樸

    比較基準為相同平均電池電流。若電池實際承受 0～1 A、50% 占空比的方波，總 RMS 為 0.707 A，比 0.5 A DC 高 41.4%。在 AC 與 DC 等效電阻相同時，平均電阻發熱增加 100%。

    電池實際承受兩階電流時的發熱

    輸入電池支路量到的高、低電流及高態時間比例。Rac 是對漣波頻譜採用的等效耗散電阻。

    電池電流同平均值 DC
    Iavg = D·Ion + (1−D)·Ioff
    Irms = √[D·Ion² + (1−D)·Ioff²]
    Iac,rms = |Ion−Ioff|√[D(1−D)]
    Pdc = Iavg²·Rdc，ΔP = Iac,rms²·Rac

    若阻抗隨頻率變化，以各諧波的 RMS² 乘上該頻率的 Re{Z} 再求和。當電流反向時，本區仍只計算電阻耗散。

    輸出電容分流多少電流？

    指定一個頻率下的電池複數阻抗與電容參數。把上游漣波視為注入輸出節點的單頻電流源。

    頻率按鈕只改 f。比較實際頻點時，請同步輸入該頻率的 Zbat。兩支路電流為相量，RMS 幅值不能直接相加。

    Zc = ESR + j(2πf·ESL − 1/(2πf·C))
    Ibat / Iinj = Zc / (Zbat + Zc)
    IC / Iinj = Zbat / (Zbat + Zc)

    電流與發熱

    i(t) = Idc + iac(t), <iac> = 0
    Iac,rms = Ipp / (2√2)　[正弦]
    Iac,rms = Ipp / (2√3)　[對稱三角波]
    Iac,rms = Ipp / 2　[對稱方波]
    Itotal,rms = √(Idc² + Iac,rms²)
    Pdc = Idc² Rdc
    Pac = Iac,rms² Re{Z(f)}
    ηheat = Pac / Pdc
    ΔVpp = Ipp |Z(f)|　[單頻正弦]

    只有 AC 與 DC 等效電阻相同時，發熱比例中的電阻才可約去。多諧波需用 Σ In,rms² Re{Z(nf)}；本版非正弦波只開放頻率無關的純電阻近似。感抗／容抗影響電壓幅度與相位，不直接作為損耗電阻。

    頻率與 1RC

    Z(ω) = R₀ + Rₚ / (1 + jωτ)
    Re{Z} = R₀ + Rₚ / [1 + (ωτ)²]
    Im{Z} = −Rₚωτ / [1 + (ωτ)²]
    Rdc = R₀ + Rₚ；ω = 2πf

    此 DC 值代表 1RC 的長時間極限。若採用脈衝 DCIR，必須註明脈衝時間。高頻電感與導線壓降應在量測參考面中清楚定義。

    SOC 上下界

    d = Idc Rdc / Ns，a = Ipk |Z| / Ns
    DC：Vmin + d ≤ OCV(SOC) ≤ Vmax − d
    DC + ripple：Vmin + d + a ≤ OCV(SOC) ≤ Vmax − d − a
    ΔSOC_pp = SpanDC − Spanripple　[百分點]
    Relative reduction = ΔSOC_pp / SpanDC × 100%

    均衡且一致的串聯單體是假設。並聯結構只要電流、容量、阻抗皆以模組端輸入即可；本版不分析支路分流。圖中單體電壓由模組電壓除 Ns 推得，不能代表最差單體。

    穩態熱與 Arrhenius

    Rθ = ΔTdc / Pdc　[已知基準溫升模式]
    ΔTac = Pac Rθ
    Tdc,K = Tamb + ΔTdc + 273.15
    Tac,K = Tdc,K + ΔTac
    AF = exp[(Ea / Rg)(1/Tdc,K − 1/Tac,K)]
    Rate increase = (AF − 1) × 100%；Rg = 8.314462618 J/(mol·K)

    熱阻對應同一模組與散熱邊界。模型僅以平均不可逆電阻損耗估算溫升，忽略可逆熵熱、熱梯度與暫態。若已知溫升還含其他熱源，不可直接反推為相同的電阻發熱熱阻。
