# RippleTechs

電池充電電流漣波分析、單級 AC–DC 充電器取捨，以及可控漣波的電路方案。這個儲存庫整理互動工作台、技術校核、原理圖及工程範例。

## 開始使用

下載 [電池 Ripple 分析工作台 v1.2（離線 HTML）](workbench/電池Ripple_分析工作台_v1.2_離線單檔.html)。工作台的校核結果與已知限制請見 [v1.2 校核紀錄](docs/工作台v1.2_校核紀錄.md)。在 GitHub 檔案頁選 **Download raw file**，再用瀏覽器開啟下載的 `.html`。試算、波形和電路圖都包含在單檔中。點開原廠文件或論文連結時才需要網路。

- **估算工作台**：從 39.03 A、75 A 案例開始，調整平均電流、漣波大小、頻率及阻抗，查看電壓波形、額外耗散和 CSV 結果。
- **SOC 電壓窗**：匯入 OCV–SOC 資料後，估算在單體電壓限制下的可用範圍。
- **開關漣波校核**：輸入電池端高低態電流與占空比，分別看 RMS 電流與發熱增幅。另可試算輸出電容的複數阻抗分流、比較多相 Buck 的合流漣波，並切換電路圖。
- **單級充電取捨、五頁校核、操作與公式**：查閱原始算例、模型條件及資料需求。

## 討論中確認的工程重點

### 先在電池支路量電流

Switch Unit 的開關管、電感與電池支路各有自己的電流波形。電池端是否承受完整的通斷脈衝，要由拓樸與實測決定。0–325 V 則是 **230 Vac 全波整流後，一次側小容量濾波條件下的理想範圍**。電池電壓量在二次側電池正負端。

### 分別比較 RMS 電流與發熱

用同一個固定電阻比較平均 0.5 A 的三種電池端波形：

| 電池電流波形 | 總 RMS 電流 | 相對 0.5 A DC 的額外電阻熱 |
|---|---:|---:|
| 0.5 A DC | 0.500 A | 0% |
| 0–1 A 兩階波，50% 占空比 | 0.707 A | +100% |
| 0.3–0.7 A 三角波 | 約 0.513 A | 約 +5.33% |

兩階波的 **+41.4% 是總 RMS 電流增幅**。平均電阻發熱是 0.5 A DC 的兩倍。頻率相依時，漣波耗散以各諧波的 `I_rms² × Re{Z}` 加總。TI BQ25758S 的 `I_CHG × √[D(1−D)]` 用於其輸入電容 RMS 估算，輸出電容有獨立公式。[TI 資料手冊 §8.2.1.2.3–5](https://www.ti.com/lit/ds/symlink/bq25758s.pdf)

### 高頻開關漣波與 100／120 Hz 漣波分開處理

| 漣波來源 | 設計方式 |
|---|---|
| 開關頻率及其諧波 | 以輸出電感、並聯電容、交錯多相或耦合電感降低。電容分流取決於電池與電容的複數阻抗。交錯抵消與占空比、相位及導通模式有關。 |
| 單相市電的兩倍頻 | 市電過零附近需要補足瞬時功率。兩級可用母線電容。單級主功率路徑可用並聯主動功率解耦（APD），在能量窗口允許時設定殘留漣波。 |

理想單相、近似單位功率因數、忽略損耗並假設電池電壓固定時，100 W／50 Hz 的例子把同步電池電流漣波係數 `m = I_ac,pk / I_dc` 設成 0.1。APD 的瞬時功率幅度約 90 W，儲能峰峰差約 0.2865 J。若儲能電容使用 60–100 V 電壓窗，理想容量下限約 89.5 µF。60 Hz 電網（120 Hz 漣波）時，儲能峰峰差約 0.2387 J，下限約 74.6 µF。這是理論下限，選型時還要加上電容公差、老化衰減和控制裕度。完整範例（待上傳）· [APD 參考研究](https://doi.org/10.3390/en16217450)

| 獨立電路圖 | 適用情境 |
|---|---|
| 切換式並聯電容（`figures/passive.png` 待上傳） | 分檔調整高頻分流，需處理預充及切換瞬態。電池阻抗為 mΩ 等級時，並聯電容在 100/120 Hz 幾乎無法分流（見校核紀錄） |
| 兩開關並聯 APD（`figures/apd.png` 待上傳） | 單級主路徑保留可設定的同步低頻漣波 |
| DAB 二次側整合解耦（`figures/integrated.png` 待上傳） | 以特定拓樸及調變整合能量緩衝 |
| 同步 Buck（`figures/buck.png` 待上傳） | 有儲能的母線供應可程式正向電流 |
| 四開關雙向 Buck-Boost（`figures/bidir.png` 待上傳） | 追蹤正、負電流指令，需能量回收路徑 |

## 模型與實測的對照

工作台提供工程試算。量產設計應使用同一組電池工作點的實測電流波形、EIS／DCIR、SOC、溫度與 BMS 限制。低頻試算應另外檢查 PF／THD、暫態、儲能電壓窗口和 APD 元件的峰值及 RMS 電流。發熱估算無法直接換算為 SOH 或壽命，分享對話引用的 40 App／250 kHz 壽命主張未納入設計依據。電路圖呈現功率級原理，驅動、保護與元件選型仍需實作驗證。
