    CHARGER / BATTERY CO-DESIGN

    單級充電器省成本，合理嗎？

    有條件合理。把電池可接受的 ripple 納入充電器設計，可能降低級數、電容、磁性元件與散熱成本。但應先訂電池端的頻譜、RMS、峰值與溫升界限，再比較整機成本。

    先分清楚：級數不等於 ripple 大小

    單相、近似單位功率因數時，瞬時輸入功率含兩倍線頻脈動：50 Hz電網為100 Hz，60 Hz電網為120 Hz。若能量緩衝很少且電池電壓近似固定，電池電流可能接近0–2Idc。單級也能設計解耦；二級也能刻意容許ripple以縮小DC-link電容。理想平衡三相的總瞬時功率沒有相同的固有2f脈動。

    p(t) = Pavg[1 − cos(2ωline t)]
    i(t) ≈ Idc[1 − cos(2ωline t)]　[無顯著能量緩衝的理想單相例]
    m = Ipk / Idc；Ipp / Idc = 2m
    Pac/Pdc = ½m² × Re{Z}/Rdc　[正弦]

    成本判斷應用「BOM與製造節省 − 新增解耦／散熱／EMI／驗證成本 − 能耗差額 − 電池壽命與保固成本」。級數變少不保證整機效率或成本較佳；也不要把0.23%的速率數值直接換成電池折舊。

    驗收分兩層

    1. 短期電氣與熱：相同平均充電任務、環境與冷卻條件，比較電芯／接點溫升、峰值電流、單體峰值電壓、CC–CV時間、充入Ah／Wh、BMS判斷，以及輸入功率品質／EMI。界限依電芯與系統規格制定。
    2. 中長期壽命：同批DC與ripple對照，匹配SOC／DoD／Ah；一組同冷卻邊界比較總影響，另一組同電池溫度以分離直接ripple效應。以容量、阻抗與統計不確定度作判準。

    與此用途直接相關的研究

    Ghassemi et al., 2019：13顆LFP的100 Hz實驗在其條件下未觀察顯著額外衰退，支持縮小電容的研究方向。2022延伸研究指出幅度、頻率與極化需要合併判斷，低頻微循環可能增加衰退。以上已核對作者機構摘要，不能直接當作本電芯的允許值。

    Xue et al., 2015在二級架構實作容許兩倍線頻的正弦充電以縮小DC-link電容，說明可節省緩衝能量的方案不只「二級改一級」。

    電池實際承受兩階電流時的發熱

    輸入電池支路量到的高、低電流及高態時間比例。Rac 是對漣波頻譜採用的等效耗散電阻。

    電池電流同平均值 DC
    Iavg = D·Ion + (1−D)·Ioff
    Irms = √[D·Ion² + (1−D)·Ioff²]
    Iac,rms = |Ion−Ioff|√[D(1−D)]

    SINGLE-PHASE 2f RIPPLE

    100／120 Hz 漣波深入分析

    單相充電器的輸入功率含兩倍市電頻率的脈動。充電器的能量緩衝吸收多少，決定電池承受多少。本頁假設理想單相、功率因數 1、無損耗，且電池電壓近似固定：電池電流 i(t) = Idc·[1 − m·cos(2ωt) + h₄·m·cos(4ωt)]。m = 0 是兩級全緩衝，m = 1 是單級完全不緩衝。阻抗預設值為示範參數，請以實測 EIS 擬合取代。

    模型條件與提醒

      緩衝程度 m 的取捨

      同一工作點下，從兩級全緩衝（m = 0）到單級不緩衝（m = 1）。電池側代價隨 m² 上升，緩衝能量隨 (1 − m) 線性下降。

      50 Hz 與 60 Hz 電網比較

      60 Hz 電網的漣波頻率較高，所需緩衝能量少 1/6；同時更多電流走雙電層路徑，介面過電位略低。

      CV 進入點

      怎麼解讀這些數字

      1. 發熱要用 Re{Z(2f)}。它介於 R₀ 與 Rdc 之間。Rdc 含擴散等慢極化，100/120 Hz 看不到這部分，所以正弦 ripple 的發熱比通常低於 ½m²：示範參數下 m = 1 約 +37%，不是純電阻假設的 +50%。反過來，用 10 kHz 的阻抗會低估發熱。低溫時 R₁ 上升，Re{Z(2f)} 會明顯增加。
      2. 100/120 Hz 會真正驅動電化學反應。電荷轉移的轉角頻率 1/(2πτ₁) 通常在數十到數百 Hz。示範參數（τ₁ = 2 ms）下，約 55–62% 的漣波電流經過電荷轉移反應；在 10 kHz 不到 1%。所以 10 kHz 開關漣波主要是歐姆發熱，100/120 Hz 才有鋰嵌入、脫出的微循環。
      3. 微循環極淺。每個線週期的 SOC 擺動約 10⁻⁵ % 等級，遠小於一般充放電循環。壽命風險主要不在 SOC 擺動本身，而在介面過電位峰值和溫升。
      4. 析鋰風險看介面過電位的總峰值（DC＋AC）。低溫、高 SOC、大電流時最嚴重。用「R₁ 與 τ₁ 倍率」模擬低溫（雙電層電容不變，所以 τ₁ 跟著 R₁ 變大）。在線性模型中，R₁ 變大時 100/120 Hz 的介面擺動會被 1/(2πf·C₁) 限住，大幅增加的是 DC 過電位 Idc·R₁；所以低溫時應先限制平均電流，ripple 峰值再疊加上去。是否真的析鋰，要用參考電極電芯或電化學模型確認負極電位；本頁只提供相對比較。
      5. CV 階段的電壓限制。充電器若對瞬時端電壓限壓，端電壓峰值會讓 CV 提前、充電時間變長。若以濾波後的電壓控制，平均電壓可達上限，但介面過電位仍會在其上擺動。
      6. BMS 量測。電流取樣若低於 2 × 2f 又沒有抗混疊濾波，2f 漣波會折疊到低頻；取樣頻率剛好整除 2f 時會折疊到 0 Hz，庫侖計數出現與取樣相位有關的固定偏差。
      7. 4f 諧波。PFC 電流失真、控制頻寬不足或母線電壓漣波都會產生 4f 等諧波。它們同樣計入發熱與電壓峰值，量測時要看完整頻譜。

      100/120 Hz 驗收建議

      • 在電池正負端量電流，探頭頻寬至少 10 kHz；做 FFT，分別記錄 2f、4f 與開關頻率分量。
      • 在相同 SOC 與溫度量 EIS（至少 1 Hz–10 kHz），擬合 R₀、R₁τ₁、R₂τ₂；另量 0 °C 與 10 °C。
      • 以相同平均電流比較 DC 與 ripple 充電：電芯與接點溫升、CV 進入時間、總充電時間、充入 Ah。
      • 低溫充電以參考電極電芯或電化學模型確認負極電位峰值。
      • 確認 BMS 電流量測的抗混疊濾波與庫侖計數誤差。
      • 壽命驗證用同批電芯的 DC 對照組，並分成「同冷卻條件」與「同電池溫度」兩組，以分離溫升與直接 ripple 效應。

      公式

      pin(t) = P[1 − cos(2ωt)]，P = Vbat·Idc
      pbat(t) = Vbat·i(t)，pbuf = pin − pbat
      Epp = max∫pbuf dt − min∫pbuf dt；只有 2f 時 Epp = P(1 − m) / (2π·fgrid)
      C_APD = Epp / [½(Vhi² − Vlo²)]，C_link = Epp / (Vbus²·r)
      Pac = ½(I₂² Re{Z(2f)} + I₄² Re{Z(4f)})，Pdc = Idc² Rdc
      ΔSOCpp = ΔQpp / (3600·Ah) × 100%
      f_alias = |2f − k·fs|，摺疊到 [0, fs/2]

      相關研究見「單級充電取捨」與「五頁校核」頁的連結（Ghassemi 2019、2022 延伸研究、Xue 2015、Steinstraeter 2022）。它們的結論依電芯、頻率、幅度與溫控條件而定，不能直接當作本電芯的允許值。

      先統一量測基準，再調整參數

      1. 選擇 39.03 A 原圖或 75 A 案例。兩者都使用 5.38 App 正弦 ripple。39.03 A 沿用原圖的 20 K DC 溫升；75 A 改用由 39.03 A 反推的同一熱阻 1.766 K/W，避免把不同散熱系統放在一起比較。
      2. 確認 ripple 為峰對峰、峰值或 RMS。只填 AC 分量；不要把含 DC 的總 RMS 當作 AC RMS。
      3. 選阻抗模型。已知 EIS 時，輸入同一模組、同 SOC／溫度／頻率的 Re{Z}、Im{Z}，另填 DC 有效電阻。2RC＋L 模式會由頻率計算阻抗，並把電壓拆成歐姆壓降與介面過電位。
      4. 跨電流比較同一散熱系統，使用固定熱阻；若有各工況的實測 DC 溫升，可分別使用基準溫升模式。
      5. 進入「SOC 電壓窗」，貼上實測 OCV–SOC 表並套用。未提供曲線時不輸出 SOC 縮減數字。
      6. 匯出 CSV，保留參數、單位、曲線來源與估算結果。所有計算在瀏覽器內執行，重新整理會回到預設；請先匯出。

      電流與發熱

      i(t) = Idc + iac(t), <iac> = 0
      Iac,rms = Ipp / (2√2)　[正弦]
      Iac,rms = Ipp / (2√3)　[對稱三角波]
      Iac,rms = Ipp / 2　[對稱方波]
      Itotal,rms = √(Idc² + Iac,rms²)
      Pdc = Idc² Rdc
      Pac = Iac,rms² Re{Z(f)}
      ηheat = Pac / Pdc
      ΔVpp = Ipp |Z(f)|　[單頻正弦]

      只有 AC 與 DC 等效電阻相同時，發熱比例中的電阻才可約去。多諧波需用 Σ In,rms² Re{Z(nf)}；本版非正弦波只開放頻率無關的純電阻近似。感抗／容抗影響電壓幅度與相位，不直接作為損耗電阻。

      頻率與 2RC＋L

      Z(ω) = R₀ + jωL + R₁/(1 + jωτ₁) + R₂/(1 + jωτ₂)
      Zohm = R₀ + jωL；Zint = R₁/(1 + jωτ₁) + R₂/(1 + jωτ₂)
      Re{Rₖ/(1 + jωτₖ)} = Rₖ / [1 + (ωτₖ)²]，Im = −Rₖωτₖ / [1 + (ωτₖ)²]
      經電荷轉移的電流比例 = 1 / |1 + jωτ₁|
      Rdc = R₀ + R₁ + R₂；ω = 2πf

      R₁、τ₁ 對應電荷轉移與雙電層（轉角頻率通常為數十到數百 Hz），R₂、τ₂ 對應擴散等慢極化。此 DC 值代表長時間極限。若採用脈衝 DCIR，必須註明脈衝時間。高頻電感與導線壓降應在量測參考面中清楚定義。

      SOC 上下界

      d = Idc Rdc / Ns
      a = Ipk |Z| / Ns（端電壓）、Ipk |Zint| / Ns（介面）或 0（濾波後）
      僅充電側：OCV(SOC) ≤ Vmax − d − a → CV 進入點
      充放電交集：Vmin + d + a ≤ OCV(SOC) ≤ Vmax − d − a
      ΔSOC_pp = SpanDC − Spanripple　[百分點]
      Relative reduction = ΔSOC_pp / SpanDC × 100%

      均衡且一致的串聯單體是假設。並聯結構只要電流、容量、阻抗皆以模組端輸入即可；本版不分析支路分流。圖中單體電壓由模組電壓除 Ns 推得，不能代表最差單體。

      穩態熱與 Arrhenius

      Rθ = ΔTdc / Pdc　[已知基準溫升模式]
      ΔTac = Pac Rθ
      Tdc,K = Tamb + ΔTdc + 273.15
      Tac,K = Tdc,K + ΔTac
      AF = exp[(Ea / Rg)(1/Tdc,K − 1/Tac,K)]
      Rate increase = (AF − 1) × 100%；Rg = 8.314462618 J/(mol·K)

      熱阻對應同一模組與散熱邊界。模型僅以平均不可逆電阻損耗估算溫升，忽略可逆熵熱、熱梯度與暫態。若已知溫升還含其他熱源，不可直接反推為相同的電阻發熱熱阻。
